# Customer Engagement and Analytics Portfolio

## Overview

This case study demonstrates the analysis, redesign and implementation of a customer communication performance analytics solution.

## Skills Demonstrated

- Business Analysis
- Process Mapping
- Requirements Gathering
- SQL Development
- Data Validation & Reconciliation
- Data Quality Management
- Power Query
- Data Modelling
- DAX Development
- KPI Design
- Power BI Reporting
- Stakeholder Engagement
- Service Improvement

## Portfolio Contents

### 1. Current State Process (As-Is)
Mapped the existing campaign management and performance measurement process.

### 2. Pain Point Analysis
Identified operational inefficiencies and reporting challenges.

### 3. Business Requirements & Stakeholders
Captured business objectives, functional requirements and stakeholder needs.

### 4. Future State Process (To-Be)
Designed an improved semi-automated reporting process.

### 5. Solution Architecture
Documented the end-to-end data flow from campaign files through Power BI reporting.

### 6. Benefits Realisation
Demonstrated operational, reporting and strategic benefits delivered.

## Outcome

The solution reduced manual reconciliation activity, improved KPI accuracy, improved campaign visibility and provided a single source of performance information for management reporting.
